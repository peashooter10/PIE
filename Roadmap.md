**PIE**(Private Interactive Environment) is a cloud&live file-sync app that allows its users to upload and download files on a server and to even sync up files, whatever their type, on different devices, from PC to Mobile, Windows, Linux or Android.
**Roadmap**
1. MySQL database 
    a) Model a normalised database
    b) Create the database using Python scripts
    Progress until here :)
2. FastAPI backend
    a) Upload and download a file on a device using FastAPI cloud
    b) Upload and download a file on any device in the network
    c) Implement user accounts
    d) Implement watchdog library in python to see changes in files 
    e) Implement a system to commit files
    f) Include a back-up database using a master-slave dynamic
3. Svelte frontend
    a) Create/Login into account page
    b) Main page to upload/download files
    c) Page to manage pages in sync
