**PIE**(Private Interactive Environment) is a cloud&live file-sync app that allows its users to upload and download files on a server and to even sync up files, whatever their type, on different devices, from PC to Mobile, Windows, Linux or Android. <br><br>
**Roadmap**
1. MySQL database <br>
    a) Model a normalised database <br>
    b) Create the database using Python scripts <br>
    Progress until here :)
2. FastAPI backend<br>
    a) Upload and download a file on a device using FastAPI cloud<br>
    b) Upload and download a file on any device in the network<br>
    c) Implement user accounts<br>
    d) Implement watchdog library in python to see changes in files <br>
    e) Implement a system to commit files<br>
    f) Include a back-up database using a master-slave dynamic<br>
3. Svelte frontend<br>
    a) Create/Login into account page<br>
    b) Main page to upload/download files<br>
    c) Page to manage pages in sync
